# SportHub ecommerce UI

A responsive multipage sports ecommerce frontend for Football, Tennis, Cricket, Basketball and Badminton.

## Run
Open `index.html` in a browser, or serve the folder with any static server.

## Pages
- Home: `index.html`
- Shop: `shop.html`
- Category: `category.html?cat=Football`
- Product: `product.html?id=1`
- Cart: `cart.html`

The cart uses localStorage. Checkout is intentionally a frontend demo and can be connected to Stripe, Shopify, WooCommerce or another backend later.
